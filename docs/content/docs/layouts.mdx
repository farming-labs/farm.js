# Layouts

Layouts allow you to share UI components across multiple pages. Farm.js supports nested layouts similar to Next.js App Router.

## Root Layout

Every Farm.js application must have a root layout in `src/app/layout.tsx`:

```tsx title="src/app/layout.tsx"
import type { LayoutProps, Metadata } from 'farm'

export const metadata: Metadata = {
  title: 'My Farm.js App',
  description: 'Built with Farm.js'
}

export default function RootLayout({ children }: LayoutProps) {
  return (
    <html lang="en">
      <body>
        <header>
          <nav>
            <a href="/">Home</a>
            <a href="/about">About</a>
          </nav>
        </header>
        <main>{children}</main>
        <footer>
          <p>&copy; 2024 My App</p>
        </footer>
      </body>
    </html>
  )
}
```

## Nested Layouts

Create nested layouts by adding `layout.tsx` files in subdirectories:

```tsx title="src/app/dashboard/layout.tsx"
import type { LayoutProps } from 'farm'

export default function DashboardLayout({ children }: LayoutProps) {
  return (
    <div className="dashboard">
      <aside>
        <nav>
          <a href="/dashboard">Overview</a>
          <a href="/dashboard/settings">Settings</a>
          <a href="/dashboard/profile">Profile</a>
        </nav>
      </aside>
      <div className="content">
        {children}
      </div>
    </div>
  )
}
```

This layout will wrap all pages in the `/dashboard` route:

```
src/app/
├── layout.tsx              # Root layout
├── page.tsx                # Home page (uses root layout)
└── dashboard/
    ├── layout.tsx          # Dashboard layout
    ├── page.tsx            # /dashboard (uses both layouts)
    ├── settings/
    │   └── page.tsx        # /dashboard/settings (uses both layouts)
    └── profile/
        └── page.tsx        # /dashboard/profile (uses both layouts)
```

## Layout Props

Layouts receive the following props:

```tsx
import type { LayoutProps } from 'farm'

export default function MyLayout({ children, params }: LayoutProps) {
  // children: The page content or nested layout
  // params: Route parameters from dynamic segments
  
  return (
    <div>
      <h1>Section: {params.section}</h1>
      {children}
    </div>
  )
}
```

## Metadata

Layouts can export metadata that will be merged with page metadata:

```tsx title="src/app/blog/layout.tsx"
import type { LayoutProps, Metadata } from 'farm'

export const metadata: Metadata = {
  title: {
    template: '%s | My Blog',
    default: 'My Blog'
  },
  description: 'Welcome to my blog'
}

export default function BlogLayout({ children }: LayoutProps) {
  return (
    <div className="blog-layout">
      <header>
        <h1>My Blog</h1>
      </header>
      {children}
    </div>
  )
}
```

## Layout Hierarchy

Layouts are nested from the root to the most specific:

```
Root Layout
└── Dashboard Layout
    └── Settings Layout
        └── Page Content
```

Each layout wraps the content of its children, creating a nested structure that allows for shared UI at different levels of your application.
