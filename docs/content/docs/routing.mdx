# Routing

Farm.js uses a file-based routing system similar to Next.js App Router. Routes are defined by the file structure in your `src/app` directory.

## Basic Routing

### Pages

Create a page by adding a `page.tsx` file:

```tsx title="src/app/about/page.tsx"
export default function AboutPage() {
  return <h1>About Us</h1>;
}
```

This creates a route at `/about`.

### Nested Routes

Create nested routes by creating folders:

```
src/app/
├── page.tsx           # /
├── about/
│   └── page.tsx       # /about
└── blog/
    ├── page.tsx       # /blog
    └── posts/
        └── page.tsx   # /blog/posts
```

## Dynamic Routes

### Single Dynamic Segment

Use square brackets to create dynamic routes:

```tsx title="src/app/users/[id]/page.tsx"
import type { PageProps } from "farm";

export default function UserPage({ params }: PageProps) {
  const { id } = params;

  return <h1>User: {id}</h1>;
}
```

This matches `/users/123`, `/users/abc`, etc.

### Catch-all Routes

Use `[...slug]` for catch-all routes:

```tsx title="src/app/blog/[...slug]/page.tsx"
import type { PageProps } from "farm";

export default function BlogPost({ params }: PageProps) {
  const { slug } = params; // slug is a string like "2024/01/hello-world"

  return <h1>Blog Post: {slug}</h1>;
}
```

This matches `/blog/2024`, `/blog/2024/01`, `/blog/2024/01/hello-world`, etc.

### Optional Catch-all Routes

Use `[[...slug]]` for optional catch-all routes:

```tsx title="src/app/docs/[[...slug]]/page.tsx"
import type { PageProps } from "farm";

export default function DocsPage({ params }: PageProps) {
  const { slug } = params;

  if (!slug) {
    return <h1>Documentation Home</h1>;
  }

  return <h1>Docs: {slug}</h1>;
}
```

This matches `/docs`, `/docs/getting-started`, `/docs/api/reference`, etc.

## Route Parameters

### Accessing Parameters

Route parameters are available in the `params` object:

```tsx title="src/app/products/[category]/[id]/page.tsx"
import type { PageProps } from "farm";

export default function ProductPage({ params }: PageProps) {
  const { category, id } = params;

  return (
    <div>
      <h1>Product {id}</h1>
      <p>Category: {category}</p>
    </div>
  );
}
```

### Search Parameters

URL search parameters are available in the `searchParams` object:

```tsx title="src/app/search/page.tsx"
import type { PageProps } from "farm";

export default function SearchPage({ searchParams }: PageProps) {
  const { q, filter } = searchParams;

  return (
    <div>
      <h1>Search Results</h1>
      <p>Query: {q}</p>
      <p>Filter: {filter}</p>
    </div>
  );
}
```

## Navigation

### Link Component

Use the `Link` component for client-side navigation:

```tsx
import { Link } from "farm/client";

export default function Navigation() {
  return (
    <nav>
      <Link href="/">Home</Link>
      <Link href="/about">About</Link>
      <Link href="/users/123">User 123</Link>
    </nav>
  );
}
```

### Programmatic Navigation

Use the `useRouter` hook for programmatic navigation:

```tsx
import { useRouter } from "farm/client";

export default function MyComponent() {
  const router = useRouter();

  const handleClick = () => {
    router.push("/dashboard");
  };

  return <button onClick={handleClick}>Go to Dashboard</button>;
}
```
