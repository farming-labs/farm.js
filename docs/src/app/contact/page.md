# Contact Farm.js

Farm.js is built in the open by [Farming Labs](https://farming-labs.dev). Most questions get the fastest answer on GitHub, where the people who write the framework read every issue and discussion.

## Bugs and feature requests

Open an issue on [GitHub](https://github.com/farming-labs/farm.js/issues). Include the Farm.js version (`farm --version` or the `@farm.js/core` version in your lockfile), your Node version and operating system, the deployment target, and the smallest project or steps that reproduce the problem. `farm doctor` prints most of that for you.

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/farming-labs/farm.js/discussions): how to structure an app, whether a feature fits Farm.js, or what you built with it. Answers there stay searchable for the next person with the same question.

## Email

Write to [contact@farming-labs.dev](mailto:contact@farming-labs.dev) for anything that should not be public: partnerships, press, questions about the [agent infrastructure waitlist](/agents#waitlist), or a request about data described in the [privacy notice](/privacy).

## Security issues

Do not open a public issue for a vulnerability. Email [contact@farming-labs.dev](mailto:contact@farming-labs.dev) with the affected package and version, what an attacker can do, and the steps to reproduce it, and we will reply there and coordinate the fix and release with you.
