## Tools and forms

**Agent-ready check.** Run the check at [/agents/check](/agents/check) only on sites you own or are allowed to test. It loads about fifteen public pages of the address you enter. Its report shows what those pages returned at that moment; it is not a certification, and a site can score differently a minute later. The number of checks one visitor can run is limited.

**Agent infrastructure waitlist.** Joining the waitlist on [/agents](/agents) means Farming Labs can email you about agent infrastructure and early access. It is not an offer, and it does not promise access by any date. Only add your own email address.

**Agents and crawlers.** Agents are welcome to read the site, including its Markdown pages, `llms.txt`, and the docs MCP server. Keep the request rate to what a person reading the docs would cause.

[Privacy](/privacy) describes what each of these tools collects and where it goes.
